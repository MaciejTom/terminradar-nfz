# Product Brief

## One-sentence Pitch

TerminRadar NFZ helps users monitor public NFZ treatment queues and get notified when a better term appears.

## User Problem

Finding a better NFZ treatment term often requires repeated manual checks. Users do not only need search results; they need monitoring, comparison and change detection.

## Core Flow

1. User searches for a treatment type and location.
2. User reviews normalized results.
3. User saves a search as a subscription.
4. Background jobs periodically check NFZ data.
5. The system stores snapshots and compares changes.
6. The user gets an alert when a meaningful improvement appears.

## MVP Value

The MVP should prove one valuable thing:

> The app can find and monitor public queue data without the user checking manually every day.
