# ADR-0008: Prioritize Scoped Delivery over Full NFZ Platform

## Status

Accepted

## Context

The initial vision includes many NFZ APIs, reliability scoring, contracts, maps and predictions. This is too broad for a first portfolio milestone.

## Decision

Start with treatment queue search, saved monitoring, snapshots and alerts.

## Alternatives Considered

- research and integrate all NFZ APIs first
- build frontend-only search first
- implement analytics before alerting

## Consequences

Pros:

- faster demoable MVP
- clearer learning path
- less risk of unfinished scope

Cons:

- advanced analytics are delayed
- some impressive ideas remain in the backlog
