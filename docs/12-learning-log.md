## 2026-05-16 - Project Foundation

### Built

Created the initial documentation and planning scaffold for TerminRadar NFZ.

### Learned

A strong portfolio project needs clear scope, phases, architecture decisions and a story that can be explained in interviews.

### Decision

Start with documentation and a scoped roadmap before scaffolding `apps/web` and `apps/api`.

### Interview Question

Why did you start with product and architecture docs before coding?

### My Answer

Because the project is meant to show mid-level ownership, not only implementation. Defining scope, non-goals and milestones helps avoid building an oversized unfinished app.
