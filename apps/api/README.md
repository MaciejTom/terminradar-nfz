# TerminRadar NFZ API

NestJS backend application for TerminRadar NFZ.

The API will own NFZ integration, response normalization, persistence, background jobs and alerting. At this scaffold stage it only contains the default NestJS starter files.

## Local Setup

```bash
pnpm install
```

## Scripts

```bash
pnpm run start:dev
pnpm run lint
pnpm run test
pnpm run build
```
