# TerminRadar NFZ Web

Next.js frontend application for TerminRadar NFZ.

The web app will provide the search experience, dashboard, saved monitoring views and alert history. At this scaffold stage it only contains a minimal placeholder page.

## Getting Started

Run the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
